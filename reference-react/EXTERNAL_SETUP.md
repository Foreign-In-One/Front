# EXTERNAL_SETUP.md — 외부 연동 현황과 필요한 준비물

PayCycle AI가 실제로 사용하는 외부 자원과, 지금 대체(Mock/수기 입력) 중인 항목을 정리합니다.

## 1. 지금 그대로 작동하는 것 (추가 준비 없음)

| 기능 | 사용 자원 | 비고 |
| --- | --- | --- |
| 문서 판독(OCR) | Lovable AI 게이트웨이 멀티모달 모델 | 별도 API 키 불필요. 플랫폼이 `LOVABLE_API_KEY`를 서버에 주입 |
| 질문카드 번역 | 같은 게이트웨이 | 한국어 원문 + 선택 언어 병기 |
| 챗봇 답변 | 같은 게이트웨이 | 저장된 데이터 요약만 컨텍스트로 사용 |
| 데이터 저장 | 브라우저 localStorage | 계정 로그인/기기 간 동기화 없음 |

관련 코드
- 서버 함수: `src/lib/paycycle/ai.functions.ts`
- 서비스 레이어: `src/services/ocr.ts`, `src/services/ai.ts`, `src/services/law.ts`

## 2. 현재 대체 중인 항목 (실제 연동 시 준비물)

| 항목 | 현재 동작 | 실제 연동에 필요한 것 |
| --- | --- | --- |
| 전문 OCR 엔진 | AI 게이트웨이 판독, 실패 시 사용자 직접 입력 | 상용 OCR(예: Google Document AI, Naver CLOVA OCR) 계정 + API 키 |
| 법령 원문 조회 | `src/lib/paycycle/law.ts`의 고정 조문 + 국가법령정보센터 링크 | 국가법령정보센터 Open API 신청(활용 승인 + OC 키) |
| 국세청 연말정산 자료 | 계산하지 않고 확인 항목만 안내 | 홈택스 간소화 자료 연계는 개인 인증(공동인증서) 기반이라 별도 심사 필요 |
| 국민연금·근로복지공단 가입내역 | 공식 문의 안내로 대체 | 공개 API 미제공. 기관 제휴 필요 |
| 입금내역 자동 연동 | 사용자가 이미지 업로드 또는 직접 입력 | 오픈뱅킹(금융결제원) 이용기관 등록 및 심사 |
| 계정/기기 간 동기화 | 없음(로컬 저장) | Lovable Cloud 활성화 후 사용자 인증 + DB 테이블 |

## 3. 개인정보 관련 운영 규칙

- 업로드한 문서 이미지는 판독 요청에만 사용하고 앱에는 금액·날짜 등 구조화된 값만 남깁니다.
- 여권번호·외국인등록번호·계좌번호는 입력하지 않도록 화면에서 안내합니다.
- 판독 실패 시 값을 추정하지 않고 "확인 불가"로 표시한 뒤 직접 입력 경로로 넘깁니다.

## 4. 표현 규칙 (법적 리스크 방지)

- "임금체불", "불법", "받을 수 있습니다" 같은 확정 표현을 쓰지 않습니다.
- 결과는 항상 `확인된 사실 / 공식 기준 / 판단 범위 / 다음 행동 / 근거 법령` 다섯 조각으로 나눠 보여 줍니다.
- 자료가 없으면 0원이 아니라 "판단 불가 / 추가 자료 필요"로 표시합니다.
