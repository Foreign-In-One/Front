# PayCycle AI — 외국인 근로자 금융권리 관리 MVP

현재 프로젝트는 빈 템플릿 상태입니다(홈이 플레이스홀더). 처음부터 서비스 전체를 새로 만듭니다. 모든 화면 문구는 한국어입니다.

## 구현 방향

- 모바일 우선 핀테크 UI(하단 5탭 + 챗봇 플로팅 버튼)
- 단일 상태 저장소(Context + localStorage 영속화) — 프로필/급여기록/타임라인/분석결과가 모든 화면에서 공유되고, 새로고침·뒤로가기에도 유지
- 금액 비교·날짜 계산·세법 Rule·상태 판정은 전부 코드(Rule Engine)에서 계산. 화면의 숫자는 고정 mock이 아니라 상태에서 파생
- 문서 업로드는 파일명·크기에 따라 값을 뽑는 mock OCR(실제 업로드가 상태를 바꿈). 질문카드 번역은 사전 정의된 이중언어 템플릿에 실제 수치를 주입
- 챗봇은 일반 채팅이 아니라, 저장된 데이터를 조회해 답하는 인텐트 기반 어시스턴트

## 화면 구성

1. **첫 화면 `/`** — "한국에서 일하면서, 내가 받을 돈을 놓치고 있지는 않나요?" + 3개 핵심 기능 요약 + [내 금융권리 관리 시작하기] / [서비스 둘러보기]
2. **온보딩 `/onboarding`** — 한 번에 한 질문씩(국적, 체류자격, 입국일, 최초 근무일, 사업장, 급여일, 예상 출국일, 언어). 진행바 + 단계 전환 애니메이션 → "내 금융권리 프로필이 만들어졌어요."
3. **대시보드 `/dashboard`** — "나의 금융권리". 상단 프로필 요약, 이번 달 급여 상태 / 올해 누적 급여(카운트업) / 연말정산 확인 항목 수 / 출국 D-DAY, 3개 메인 카드, 최근 타임라인
4. **PayCheck `/paycheck`** (비중 최대) — 계약서 → 명세서 → 입금내역 순차 업로드, [급여 비교 시작] 시 단계별 분석 애니메이션, 4개 상태(일치 확인 / 설명 필요한 차이 / 자료 부족 / 사용자 확인 필요) 결과 카드, [왜 이렇게 나왔나요?] Drawer(비교 대상·비교 결과·확인된 값·차이·추가 확인 자료), [사업주에게 물어볼 질문 만들기] → 한국어/모국어 탭 + 복사하기. 완료 시 급여기록·타임라인 자동 반영
5. **TaxCheck `/taxcheck`** — 프로필 + 누적 급여 자동 사용, Rule 3개(주택마련저축 / 19% 단일세율 비교 / 외국인 특례)로 🟢🟡 상태 산출, 카드별 현재 조건·적용 여부·추가 필요 정보·근거
6. **ExitCheck `/exitcheck`** — 출국일 기준 D-30/-20/-15/-7/D-Day 로드맵, 출국만기보험·귀국비용보험·국민연금 반환일시금·퇴직금 차액 4개 권리를 상태(확인 필요/준비 중/서류 부족/신청 준비 완료/기관 확인 필요)로 관리, 상태 변경 시 타임라인 기록
7. **타임라인 `/timeline`** — 월별 그룹, [기록 추가](급여/송금/저축/세금/보험/기타) 직접 입력 가능
8. **챗봇** — 모든 화면 플로팅 버튼 → 시트. 타이핑 애니메이션, "이번 달 왜 적어?", "올해 받은 급여", "연말정산 준비", "출국 전 받을 돈", "지금 확인해야 할 것" 등을 실제 저장 데이터로 답변하고 해당 화면으로 이동 링크 제공

## 표현 규칙

- "임금체불", "불법 공제", "지급됩니다" 같은 확정·법적 판단 문구는 사용하지 않음. 차이 사실과 확인 필요 항목만 서술

## 기술 메모

- TanStack Router 파일 라우트, 상태는 `src/state/paycycle-context.tsx`(reducer + localStorage), 로직은 `src/lib/`의 rule-engine·mock-ocr·chat-intent 모듈로 분리
- 디자인 토큰은 `src/styles.css`에 신뢰감 있는 핀테크 팔레트(딥 네이비 + 시그널 그린/앰버)로 정의, 하드코딩 색상 미사용
- 라우트별 한국어 head() 메타 설정
- 구현 후 Playwright로 데모 시나리오(프로필 생성 → PayCheck 12만원 차이 → 질문카드 → 타임라인 반영 → TaxCheck/ExitCheck → 챗봇) 전체를 실제 클릭 테스트

## 백엔드

MVP는 로컬 저장으로 완결됩니다. 계정 로그인·기기 간 동기화·실제 문서 OCR이 필요하면 이후 단계에서 Lovable Cloud를 붙이면 됩니다.
